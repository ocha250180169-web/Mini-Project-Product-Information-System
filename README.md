# Product Information System

Mini Project 1 - Product Information System (Desain)

## Struktur File

- `products.php` = Data Layer
- `functions.php` = Processing Layer
- `index.php` = Presentation Layer

## Konsep

Sistem menggunakan:
- Multidimensional array untuk menyimpan data produk.
- Fungsi `hitungTotalNilaiStok()` untuk menghitung nilai aset/stok.
- Conditional untuk memberi warna pada baris jika stok kurang dari 3.
- `require_once` untuk menghubungkan komponen.
- `foreach` untuk menampilkan data ke tabel HTML.

## Catatan

Project ini dibuat sesuai instruksi Mini Project 1.
